# 💧《小水滴的三態變身大冒險》3D 科學闖關遊戲

依據 [小水滴的三態變身大冒險_3D遊戲開發規格書_v1.1.md](./小水滴的三態變身大冒險_3D遊戲開發規格書_v1.1.md) 與主視覺設定圖打造的原創 3D 科學解謎闖關遊戲，適合國小三、四年級自然科學教學與自主探索。

---

## 🚀 安裝與啟動方式

在專案資料夾（`C:\Users\user\Desktop\水的三態教學app`）開啟終端機執行：

```bash
# 1. 安裝依賴套件
npm install

# 2. 啟動本機開發伺服器
npm run dev

# 3. 正式環境打包建置測試
npm run build
```

---

## 🎮 操作說明

| 按鍵 | 功能 | 說明 |
| :--- | :--- | :--- |
| **W / A / S / D** 或 **方向鍵** | 前後左右移動 | 鏡頭以斜上方約 35 度平順跟隨，免手動轉視角 |
| **Space（空白鍵）** | 跳躍 | 具地面碰撞檢測，防止無限連跳 |
| **E** | 操作環境裝置 | 靠近冷卻機、暖氣區、暖陽蒸發區或冷空氣凝結區時按 E 觸發相變 |
| **M** | 三態粒子觀察鏡 | 隨時開啟固態、液態、氣態粒子運動示意與科學比較表 |
| **H** | 科學小精靈提示 | 分層提示先引導觀察環境，再提示操作方法 |
| **Esc** | 暫停 / 切換關卡 | 隨時重新嘗試或切換三大關卡 |

## ✨ 已完成功能（涵蓋 M0 ~ M4 全階段）

1. **原創真 3D 主角「滴滴」(`src/game/WaterCharacter.ts`)**：
   - **💧 液態（小水滴）**：`LatheGeometry` 上尖下圓立體水滴、`MeshPhysicalMaterial` 晶瑩折射高光、Q 彈行走變形（Squash & Stretch）。
   - **🧊 固態（小冰滴）**：切角冰晶立方體、稜線高光、環繞小冰晶粒子、冰面滑行慣性。
   - **☁️ 氣態（水蒸氣示意）**：半透明蓬鬆流線雲團＋上升氣流環，並明確標示「真正的水蒸氣肉眼看不見，畫面角色只是遊戲示意」。
   - **跨三態共通元素**：同一組不透明 3D 圓形大眼睛、雙眼神高光、粉紅腮紅與微笑嘴形，置於透明殼前方避免透明排序閃爍。
2. **三大完整 3D 關卡 (`src/game/LevelBuilder.ts`)**：
   - **第一關｜冰雪王國（MVP 核心關）**：液態進場 ➔ 急凍冷卻機凝固成冰 ➔ 壓下重量開關開啟冰晶門 ➔ 暖氣加熱區受熱融化回液態 ➔ 穿過細縫水道抵達終點。
   - **第二關｜水滴迷宮**：體驗液態水無固定形狀可穿過細縫濾網、固態冰塊壓開水閘門的雙段解謎。
   - **第三關｜天空之城**：暖陽區受熱蒸發（不必到 100°C）➔ 乘上升氣流柱飛上高空雲端島 ➔ 高空冷空氣區遇冷凝結成小水滴完成自然水循環。
3. **教室電腦效能降級模式**：右上角可一鍵切換「⚡ 高畫質 / 💻 教室流暢」模式，並內建 Web Audio API 程序化音效與靜音開關。
